把每个 agent 的技能
收进一个面板

DSH 会在磁盘上发现技能，却没有界面告诉你装了哪些、哪个正开着。 这个插件补上那一页：左侧导航多一行「技能」，点开就是全部技能库。

面板能做什么

不是又一个只读列表——启停、安装、预览都在这一页完成。

一个开关

停用只是把目录移进 .disabled，字节一个不动；想用的时候再拨回来。

读完再开

在应用内读完整的 SKILL.md：frontmatter、触发条件、正文指令。

安装任意技能包

把顶层含 SKILL.md 的文件夹复制进指定根目录，原目录不移动。

从 GitHub 导入

贴一个 GitHub 链接，勾选仓库中的多个技能，一次批量导入；冲突不覆盖，失败会回滚。

卸载可反悔

卸载移进 .trash，随时恢复，确认没用再彻底删除。

五个技能库自动认

Codex、Claude Code、WorkBuddy、CodeBuddy 的目录存在就列出，各自带图标。

别人的库也能挂

加一个目录进来即可，只读浏览、复制安装；模型侧同样能看到这些技能。

自动识别的技能库

每次读取时重新探测，装了新 agent 会自动出现，删掉目录也会消失。

DeepSeek Harness 自己~/.dsh/skills

WorkBuddy 只读~/.workbuddy/skills
CodeBuddy 只读~/.codebuddy/skills

安装

仓库本身就是可安装的包，没有构建步骤。

1

打开 设置 → 插件，选择从 Git 安装。

2

填入 github:yixin2021/dsh-skills 并确认。

3

刷新窗口，左侧导航出现「技能」。

也可以直接下载打包好的 dsh-skills-0.1.0.tgz。

# 或者用 CLI
dsh plugin --profile desktop add github:yixin2021/dsh-skills

# 卸载
dsh plugin --profile desktop remove dsh-skills

它怎么工作

两半，一个包。

Host

一个 POST /api/dsh-skills 路由读写磁盘，并向 ctx.skills 注册一个 provider，让模型看到这些技能。

Client

向 sidebar.panellist 注册一行导航，向 main 注册页面本身； 颜色全部取自主题变量，跟随明暗。
